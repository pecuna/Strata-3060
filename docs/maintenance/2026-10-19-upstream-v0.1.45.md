## Import fixes and RED/GREEN evidence

### Benchmark launch regression

Independent review reproduced `NameError: name 'port' is not defined`: upstream's
host-selection change removed the local assignment while the no-server and
non-Strata-health branches still referenced it. Restored the port assignment and
passed that same value to `server_base`, retaining configurable-host/IPv6 handling.

New `tools/test_bench_main_launch.py` failed before the fix and passes afterward.
It covers empty-port launch with config/CLI port, failed-readiness process and
temporary-directory cleanup, dummy-key nondisclosure, and an occupied non-Strata
port refusing launch. No real socket or child process is used in these tests.
Existing secure launch/host/benchmark tests passed alongside it.

### Golden fixture hardware isolation

Initial installer discovery ran 634 cases with three golden subtest failures.
The only configuration difference was CPU vision threads: execution host had
four logical CPUs (two encoder threads), whereas the golden fixture expects a
12-thread PC (six encoder threads). New CPU-vision defaults exposed an inherited
fixture dependency on execution-host `os.cpu_count()`.

Pinned that probe to 12 in the mocked test PC, without changing product setup
logic or rewriting golden settings. Added a regression that varies external host
counts 4/32 and requires the fixture's six encoder threads. RED before fixture
repair, GREEN after. Existing platform executable-name normalization retained.

Independent follow-up review of the four-file fix/test delta passed with no
blocker and confirmed that secure benchmark launch handling was unchanged.
It inspected the RED/GREEN logs; it did not itself execute tests.

## Independent review and limitations

Bounded runtime/API/UI and native input/cache reviews found no concrete blocker
for the documented trusted-model/configuration and trusted-client deployment.
Installer review found the benchmark bug above; follow-up review covers the fix.

Nonblocking concerns retained: logit-bias identity caching assumes immutable
input objects; prompt tokenization cache is count-bounded rather than byte-bounded.
No remote cache-content substitution was found. Local file access, explicitly
configured MCP commands/hooks, optional image capability URLs and resource
exhaustion remain in the documented threat model, not newly solved by this import.
Native raw-protocol signed arithmetic and hostile metadata are not certified safe.

No GPU build/inference, hardware performance test, full native kernel/race audit,
fuzzing, macOS/Windows execution, Windows ACL validation, production acceptance,
reboot, soak or rollback restoration was performed. A GitHub source update is not
a production deployment. Existing deployment-specific RAM-KV/long-context limits
cannot be cleared by these source/mock tests.
