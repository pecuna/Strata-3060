## Benchmark launch artifacts

The optional benchmark launcher uses a private temporary directory for launch
logs and a random atomically created 0600 config copy when removing profile-save
arguments. Existing log paths/symlinks are refused; copies are removed on spawn
failure and shutdown, including already-exited children. The original model
configuration is not overwritten. These protections do not redact arbitrary
integration credentials from every possible third-party log or secure a
compromised same-user process.
