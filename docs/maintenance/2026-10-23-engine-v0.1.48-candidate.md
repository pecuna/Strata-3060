## Speed relevance and behavior changes

Upstream `nv_defaults.cpp` reports a **9.6% RTX 3060 improvement using IQ3_XXS**
for its stacked SM86 switches. This is an upstream claim, not a measured result
for this fork or the owner's **UD-Q4_K_XL** workload. There is no local GPU speed
claim in this record.

- The SM86 table applies only when all visible CUDA devices share the matching
  compute capability. Explicit environment settings win; `STRATA_SM86_PERF=0`
  disables the table. A compiled GPU-free smoke check exercised these policies.
- `STRATA_KQ_SPLIT=1` remains an opt-in decode path for supported K-quants.
  Do not assume every K-quant optimization is automatically selected.
- `STRATA_MMQ_KQ=1` changes prompt arithmetic; existing `libstrata_kq.so`
  companion-library installation handling is retained, not newly GPU-tested.
- Automatic conversation parking is a native default change: its budget was 0
  and is now automatic, up to 8192 MiB. First qualification should explicitly use
  `--conversation-cache-mib 0` to preserve the previous off behavior.
- The new host-aware automatic prefill planner may change chunk/ring choices.
  Control it with explicit prefill settings or `STRATA_PREFILL_HOST_PLAN=0`
  during a like-for-like comparison.
- Accelerated speculative adaptation requires `STRATA_SPEC_ADAPT_SM86=1`.
  The source says earlier gains did not reproduce cleanly; it is not enabled here.
- DFlash2 is not a served-engine speed upgrade: the native code rejects its use
  with `--serve`, batching or layer splitting and falls back to MTP.

## Remaining qualification gates and known limitation

No CUDA/HIP/SYCL/Metal engine build, real-model inference, image/cancellation/
batch/session integration, Windows execution, binary publication or deployment
was performed. Source review finds the old stdin/stdout protocol still represented;
this is not an executed engine/server compatibility test.

Independent static review identified missing bounds/overflow validation in the
new **opt-in local CLI DFlash2 pack loader** (`src/core/dflash2.cpp` and the Q8
conversion in `src/kernels/cuda/dflash2.cu`). Malformed dimensions/lengths can
make conversion access beyond declared buffers. No exploit was executed and
remote API exposure was not established. Do not use untrusted draft packs; this
path is not hardened or qualified by this candidate. No security-audited-native
or deployment-ready claim is made.

Before considering a main merge or activation, require a CUDA sm_86 build,
real UD-Q4_K_XL text/image/cancellation/cache/session tests and same-day
interleaved old/new measurements with identical prompts, output lengths,
model, cache slots and explicit flags. Keep source, engine, companion libraries,
configuration and local dashboard overlays in a coherent rollback set.

Production was inspected read-only on `alex.lan`: source baseline `e3c3106a`,
`strata.service` active, MainPID 106 and zero restarts. The complete before/after
readbacks match: source revision, dirty-path list, tracked overlay diff hash,
engine/configuration hashes and service state. Nonignored untracked overlay
contents were not individually hashed. Remote publication readbacks are recorded
in the task result, not inferred from a Git push.
